# Acoustic Source Localization with Unknown Attenuation: Grey Wolf Optimizer

The project finds a sound source's 3-D position, its loudness *S* and the room's sound absorption *α* using a from-scratch **Grey Wolf Optimizer (GWO)**. The only inputs are noisy loudness readings from 20 microphones in a 50 × 50 × 10 m hall that contains an obstacle. Everything is generated from seed **4612** and reproducible.

## What's in the repo

| File | What it is |

| `report/report.pdf` | The report, about 6 pages. |
| `figures/` | 19 figures (fig01–fig19). Each has a bold one-line takeaway on top. |

## The problem in one picture

Each microphone hears `L = S − 20·log10(r) − α·r + noise`, where *r* is its distance to the source. GWO searches for the 5 unknowns `[x, y, z, S, α]` that make the predicted levels match the measured ones (least squares). It must keep the source inside the hall (handled by reflection) and outside the obstacle (handled by a smooth penalty).

## Experiments (notebook sections)

| # | Experiment | Key result |
|---|---|---|
| 4 | GWO vs random search: same 9,000 evaluations, 30 runs each | Error **2.0 m vs 4.7 m**; misfit 0.97 vs 2.76 dB² (p ≈ 10⁻¹¹) |
| 5 | Sensitivity: pack size, a(t) schedule, a0 | More early exploration (a0 = 2.5) is best; fast-decaying a(t) stalls |
| 6 | Stress: noise 1 → 3 → 5 dB, 4 microphones removed | Error 3.0 → 5.0 → 6.6 m; noise matters more than losing microphones |
| 7 | Ablation: only the α leader guides the pack | Three leaders help small packs; α-only is more precise on the main room |
| 9 | **Shot noise** (random +6…15 dB spikes) | 2 spikes move the best fit **7.7 m**; a robust **Huber loss** brings it back to about 2–3 m |
| 10 | **Parameter study**: pack size × a0 grid | a0 = 2.5 is best for every pack size; best cell is 20 wolves, a0 = 2.5 |
| 11 | **Which parameter affects f(x) most?** | **S** most (a 1 dB change adds 1 dB² of misfit); **height z** least (about 2,000× weaker) |
| 12 | **Stress by location** in the hall | Easiest in the centre; hardest under the ceiling and outside the microphone array |
| 13 | Conclusion | Summary and recommendations |

## Reproduce

```bash
pip install -r requirements.txt
pip install jupyterlab
jupyter lab gwo_acoustic.ipynb  # then Run All (~20 min), writes figures/
```

The instance is generated by `np.random.default_rng(4612)` in the order documented in `generate_instance`. Run *k* of every method and setting uses `default_rng(4612 + k)`, with *k* = 0..29. Shot-noise spikes use `default_rng(4612 + 7000)`, so the original instance is unchanged.
