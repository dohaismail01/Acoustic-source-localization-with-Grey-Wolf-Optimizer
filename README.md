# Acoustic Source Localization with Unknown Attenuation: Grey Wolf Optimizer

| File | What it is |
|---|---|
| `gwo_acoustic.ipynb` | **Main deliverable.** An executed notebook containing the formulation, code, results, and an interpretation after every table and figure. |
| `report/report.pdf` (`report.html`) | The report, about 6 pages. |
| `DEMO_PLAN.md` | A 5-minute live-demo script. |
| `figures/` | All figures (fig01–fig15). |
| `results/` | All tables as CSV, plus `summary.json`. |
| `requirements.txt` | numpy, scipy, matplotlib, pandas |

**Reproduce**

```bash
pip install -r requirements.txt
pip install jupyterlab
jupyter lab gwo_acoustic.ipynb  # then Run All (~7-8 min), writes figures/ and results/
```

The instance is generated by `np.random.default_rng(4612)` in the order documented in `generate_instance`. Run *k* of every method and setting uses `default_rng(4612 + k)`, with *k* = 0..29.
